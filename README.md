# Event Management System

## ▶️ Run the Full Stack App

### Windows
Just double-click `start.bat` — it does everything automatically!

### Mac / Linux
```bash
chmod +x start.sh
./start.sh
```

### Using npm (any OS)
```bash
# First time only — install everything:
npm install
npm run setup

# Then every time to start:
npm run dev
```
